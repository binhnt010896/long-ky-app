# Anniversary candidates (Cycle S, D-2c)

**Status: for review. Nothing here has been entered into the content.**

The app's "Hôm nay" shows an event on its anniversary when the event has an
`anniversary` (`{month, day, calendar}`, see `content/FIELD-REFERENCE.md`).
This table lists every event whose Vietnamese text mentions a day and month,
found by pattern (`ngày D tháng M` or `ngày D/M`) over `summary`, `body` and
`details`. **A match is not a date.** A sentence can mention another event's
day, or a date inside a longer campaign, so every row needs a human check
against its source before it becomes an anniversary.

How to use it: for each row write **solar**, **lunar**, **skip** or the
corrected date in the last column, then enter the approved ones in the CMS
(Events → edit → "Remembered on a day of the year").

Rules of thumb:
- **Calendar.** Dates in the old chronicles (before the 20th century) are
  normally **lunar** unless the source says *dương lịch*. Twentieth-century
  events are normally **solar**. Check the cited work, not this guess: the
  "Guess" column is only a starting point from the year.
- **One date per event.** If an event lists several, pick the one that names
  the event itself (its start, or its decisive day).
- **History, not politics.** An anniversary is a calendar fact. Leave out
  dates that would only celebrate a living office-holder.
